# 🧩 Завдання 1–2: Підготовка до роботи з проєктом Time-Slotter

### 🎯 Мета:

Створити доступ до командної розробки та підготувати робоче середовище для майбутнього проєкту

---

# 🔹 Частина 1: Доступ до репозиторію

### 📌 Що потрібно зробити:

1. Зареєструватися на GitHub (якщо акаунта ще немає)

2. Знайти репозиторій проєкту (посилання буде в групі)

3. Прийняти запрошення в команду (має бути на пошті)

---

# 🔹 Частина 2: Встановлення середовища

### 📌 Потрібно мати:

* Visual Studio (рекомендовано)
  або Visual Studio Code

* .NET SDK (версія 8+)

* Git

---

### 📌 Перевірка встановлення:

В терміналі:

```bash id="c9qk2q"
git --version
dotnet --version
```

---

# 🔹 Частина 3: Робота з репозиторієм (Git flow)

### 📌 Клонування проєкту:

```bash id="9q0v7s"
git clone <repo-url>
cd time-slotter
```

---

### 📌 Створення робочої гілки:

```bash id="4d8n3a"
git checkout -b feature/<your-name>-setup
```

---

### 📌 Створення файлу для перевірки:

Створити файл:

```
students/<your-name>.txt
```

Вписати:

* ім’я
* групу
* статус (наприклад: "environment ready")

---

### 📌 Збереження змін:

```bash id="x3k1wp"
git add .
git commit -m "Setup environment and Git workflow"
git push -u origin feature/<your-name>-setup
```

---

# 🔹 Частина 4: Pull Request

### 📌 На GitHub:

1. Створити Pull Request
2. Обрати:

   * base: `dev` (або `main`, якщо ще немає dev)
   * compare: `feature/<your-name>-setup`
3. Додати короткий опис:

   * що встановлено
   * що зроблено

---

# ✅ Результат

Студент повинен:

* мати акаунт GitHub
* мати встановлені інструменти
* вміти клонувати репозиторій
* працювати з гілками
* створити Pull Request
