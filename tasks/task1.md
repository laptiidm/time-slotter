# 🌿 Завдання 2: Клонування і перший коміт

### 🎯 Мета:

Навчитися працювати з локальним репозиторієм

### 📌 Що потрібно зробити:

1. Склонувати репозиторій:

```bash
git clone <repo-url>
```

2. Перейти в папку:

```bash
cd time-slotter
```

3. Створити файл:

```
students/<your-name>.txt
```

4. Додати в файл:

* ім’я
* групу

5. Зробити commit:

```bash
git add .
git commit -m "Add student <your-name>"
```

# 🚀 Завдання 3: Push + Pull Request

### 🎯 Мета:

Зрозуміти базовий командний workflow

### 📌 Що потрібно зробити:

1. Створити свою гілку локально:

```bash
git checkout -b feature/<your-name>
```

2. Запушити її:

```bash
git push -u origin feature/<your-name>
```

3. На GitHub:

   * створити **Pull Request**
